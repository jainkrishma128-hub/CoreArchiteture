#### 📝 Hands-On Tasks

**Day 1-2: Dockerize API Project**

Create `src/CommonArchitecture.API/Dockerfile`:
```dockerfile
FROM mcr.microsoft.com/dotnet/aspnet:9.0 AS base
WORKDIR /app
EXPOSE 80
EXPOSE 443

FROM mcr.microsoft.com/dotnet/sdk:9.0 AS build
WORKDIR /src
COPY ["CommonArchitecture.API/CommonArchitecture.API.csproj", "CommonArchitecture.API/"]
COPY ["CommonArchitecture.Application/CommonArchitecture.Application.csproj", "CommonArchitecture.Application/"]
COPY ["CommonArchitecture.Infrastructure/CommonArchitecture.Infrastructure.csproj", "CommonArchitecture.Infrastructure/"]
COPY ["CommonArchitecture.Core/CommonArchitecture.Core.csproj", "CommonArchitecture.Core/"]
RUN dotnet restore "CommonArchitecture.API/CommonArchitecture.API.csproj"
COPY . .
WORKDIR "/src/CommonArchitecture.API"
RUN dotnet build "CommonArchitecture.API.csproj" -c Release -o /app/build

FROM build AS publish
RUN dotnet publish "CommonArchitecture.API.csproj" -c Release -o /app/publish

FROM base AS final
WORKDIR /app
COPY --from=publish /app/publish .
ENTRYPOINT ["dotnet", "CommonArchitecture.API.dll"]
```

**Build and Run:**
```bash
# Build Docker image
cd src
docker build -t corearch-api:latest -f CommonArchitecture.API/Dockerfile .

# Run container
docker run -d -p 5001:80 --name api-container corearch-api:latest

# Test API
curl http://localhost:5001/api/products

# View logs
docker logs api-container

# Stop and remove
docker stop api-container
docker rm api-container
```

**Day 5-7: Docker Compose - Full Stack**

Create `docker-compose.yml` at project root:
```yaml
version: '3.8'

services:
  sqlserver:
    image: mcr.microsoft.com/mssql/server:2022-latest
    container_name: corearch-sql
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=YourStrong@Password123
      - MSSQL_PID=Developer
    ports:
      - "1433:1433"
    volumes:
      - sqldata:/var/opt/mssql
    networks:
      - corearch-network

  api:
    build:
      context: ./src
      dockerfile: CommonArchitecture.API/Dockerfile
    container_name: corearch-api
    ports:
      - "5001:80"
    environment:
      - ASPNETCORE_ENVIRONMENT=Development
      - ConnectionStrings__DefaultConnection=Server=sqlserver;Database=CoreArchDB;User Id=sa;Password=YourStrong@Password123;TrustServerCertificate=True
    depends_on:
      - sqlserver
    networks:
      - corearch-network

  web:
    build:
      context: ./src
      dockerfile: CommonArchitecture.Web/Dockerfile
    container_name: corearch-web
    ports:
      - "5002:80"
    environment:
      - ASPNETCORE_ENVIRONMENT=Development
      - ApiSettings__BaseUrl=http://api:80
    depends_on:
      - api
    networks:
      - corearch-network

volumes:
  sqldata:

networks:
  corearch-network:
    driver: bridge
```

**Run Full Stack:**
```bash
# Build all images
docker-compose build

# Start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Access applications
# API: http://localhost:5001
# Web: http://localhost:5002

# Stop all services
docker-compose down

# Rebuild and restart
docker-compose up --build -d
```

**Day 1-3: Create CI/CD Pipeline for API**

Create `.github/workflows/api-deploy-dev.yml`:
```yaml
name: Deploy API to Azure (DEV)

on:
  push:
    branches: [ development ]
    paths:
      - 'src/CommonArchitecture.API/**'
      - 'src/CommonArchitecture.Application/**'
      - 'src/CommonArchitecture.Infrastructure/**'
      - 'src/CommonArchitecture.Core/**'
      - '.github/workflows/api-deploy-dev.yml'

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    
    steps:
    - name: Checkout code
      uses: actions/checkout@v3
    
    - name: Setup .NET
      uses: actions/setup-dotnet@v3
      with:
        dotnet-version: '9.0.x'
    
    - name: Restore dependencies
      run: dotnet restore src/CommonArchitecture.API/CommonArchitecture.API.csproj
    
    - name: Build
      run: dotnet build src/CommonArchitecture.API/CommonArchitecture.API.csproj --configuration Release --no-restore
    
    - name: Test
      run: dotnet test src/CommonArchitecture.API/CommonArchitecture.API.csproj --no-restore --verbosity normal
    
    - name: Publish
      run: dotnet publish src/CommonArchitecture.API/CommonArchitecture.API.csproj -c Release -o ./publish
    
    - name: Deploy to Azure Web App
      uses: azure/webapps-deploy@v2
      with:
        app-name: 'corearch-api-dev'
        publish-profile: ${{ secrets.AZURE_WEBAPP_PUBLISH_PROFILE_API_DEV }}
        package: ./publish
```

**Get Publish Profile:**
```bash

az webapp deployment list-publishing-profiles \
  --name corearch-api-dev \
  --resource-group rg-corearch-dev \
  --xml
```

**Add to GitHub Secrets:**
1. Go to GitHub repository → Settings → Secrets and variables → Actions
2. Click "New repository secret"
3. Name: `AZURE_WEBAPP_PUBLISH_PROFILE_API_DEV`
4. Value: Paste the publish profile XML
5. Click "Add secret"

  replicas: 2
  selector:
    matchLabels:
      app: corearch-api
  template:
    metadata:

      containers:
      - name: api
